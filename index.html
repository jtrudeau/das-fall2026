Keys

→   space   PgDnnext state (during an animation: finish it)
←   PgUpprevious state
↓   ↑next / previous scene
Rreplay the current animation
Oscene list (type a number, then Enter, to jump)
Sopen the speaker view in a second window
Nshow the spoken text along the bottom of this window
B   .black screen
Tdark / light palette (use light if the room is bright)
Ffull screen
Chide / show the cursor
Zreset the timer
H   Escthis panel / close

Nothing advances on its own. A scene waits in whatever state you leave it.
